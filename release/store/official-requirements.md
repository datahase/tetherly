# Store reference checks, 10 October 2026

Primary sources only. Recheck these at the actual submission date.

- Google target API: Android 16 / API 36 for new apps and updates from August 31, 2026. Current target 36 meets this check. The old `docs/PUBLISHING.md` API 37 note is stale. https://developer.android.com/google/play/requirements/target-sdk
- Google Play icon: PNG, 512x512, maximum 1024KB. Feature graphic: RGB PNG/JPEG, 1024x500. Screenshots: minimum two across supported types; RGB PNG/JPEG, 320 through 3840px, long side at most twice short side. Large-screen guidance calls for four screenshots, 16:9 or 9:16 and 1080px minimum. Captures here use 1080x1920 or 1920x1080. https://support.google.com/googleplay/android-developer/answer/9866151
- Mac screenshots: 16:10, accepted dimensions 1280x800, 1440x900, 2560x1600, 2880x1800. The prepared composition is 2880x1800. https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/
- Mac store sandbox requirement: https://developer.apple.com/app-store/review/guidelines/#hardware-compatibility and https://developer.apple.com/documentation/security/protecting-user-data-with-app-sandbox
- Google scanner SDK disclosure: https://developers.google.com/ml-kit/android-data-disclosure
- Play Data safety interpretation: https://support.google.com/googleplay/android-developer/answer/10787469

Screen dimensions and file checks establish asset format only. They do not establish complete product acceptance, privacy compliance, or store approval.
